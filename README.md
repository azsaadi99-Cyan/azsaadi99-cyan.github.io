# Ahmed Alzahrani — personal website

Bilingual professional website: PMO/project support, network support and data analysis.

Public website: https://azsaadi99-cyan.github.io/

Static HTML, CSS and JavaScript hosted on GitHub Pages. No server, account or API key is required for visitors. The CV is intentionally public; do not add private records or credentials to this repository.

The first two project images are independently rendered analytical summaries. See their linked reports for sources, methods and limitations. Native Power BI validation is still pending. The File Finder case study uses synthetic demo messages; do not add real email, downloaded attachments, OAuth tokens or private credentials to this repository.

To preview, serve this directory with a static web server. Edit `index.html` for the home page, `file-finder.html` for its case study, `style.css` and `network.css` for shared design, `file-finder.css` for case-study design, and `app.js` for language switching. Preserve both `data-en` and `data-ar` translations. Check mobile widths, both languages, links, downloads and the video before publishing. Update the sitemap and social-preview metadata when adding a new page.

Run `node scripts/check-site.mjs` before publishing to check local assets, section links, basic page structure and translation coverage.
