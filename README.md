Bilingual professional website: Network Support, PMO and Data Analysis.

Public website: https://azsaadi99-cyan.github.io/

To preview, serve this directory with a static web server. Edit index.html for content, style.css and network.css for design, and app.js for language switching. Preserve both data-en and data-ar translations.
