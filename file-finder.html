File Finder

I built File Finder to make it easier to find documents buried in Gmail attachments. Search once, check the suggested folders and save only the files you need.

WHY I BUILT IT

The file is there. Finding it takes too long.

Invoices, purchase orders and agreements arrive from different senders. When I need one later, I don't want to open each thread and download attachments one by one. File Finder brings matching files into one list so I can check them together.

HOW IT WORKS

Search. Check. Save.

  1. 01

    Search Gmail attachments

    Narrow the results by sender, date, keywords, file type or reference number. The app shows how many messages matched and how many it checked.

  2. 02

    Check the folder suggestions

    File Finder suggests a folder using the subject, message preview and filename. Change it if needed; unclear files stay in Needs Review.

  3. 03

    Save the files you choose

    Save selected attachments into folders on your computer, with CSV and JSON records you can use later in Excel or Power BI.

ONE IMPORTANT CHOICE

A suggestion is not a final answer

A filename rarely tells the whole story. File Finder suggests where a document belongs, but leaves the decision with the person reviewing it. If there isn't enough information, it marks the file for review instead of guessing silently.

INSIDE THE APP

Check before saving

In this example, one of five attachments stays in Needs Review because its filename is too vague. The other suggested folders can be changed before anything is saved.
